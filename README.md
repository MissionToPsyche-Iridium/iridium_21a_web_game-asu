# Psyche Quest

Psyche Quest is an educational web game about the NASA Psyche mission, a satellite travelling to the Psyche asteroid. The game world is based on the Psyche spacecraft with four minigames, fixing four creatures based on the real spacecraft’s scientific instruments.

[Learn More](https://psyche.ssl.berkeley.edu/get-involved/capstone-projects/capstone-projects-iridium-class/web-based-game-for-psyche-asu-a/)

[Play](https://missiontopsyche-iridium.github.io/iridium_21a_web_game-asu/)
